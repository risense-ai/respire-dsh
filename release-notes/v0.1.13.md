## Summary

`/goal` no longer leaves automatic goal rounds blind to memory. The plugin now recalls on `source.kind === 'goal'` messages, resolving the query from the goal objective and deduplicating by goal revision.

**中文摘要：** 0.1.13 让自动 goal 轮次也能召回记忆：默认每个 goal revision 首轮召回一次，可用 `goalRecall` 改为每轮/关闭；goal 轮次不会自动写库，收尾催存默认关闭。

## Features

- **Goal-round recall** — `goalRecall: 'off' | 'first' | 'every'` (default `first`). `first` recalls once per `goalId:revision`; `/goal edit` creates a new revision and recalls again. `every` recalls on round 1 and every `goalRecallEvery` rounds. [`1f699bf`](https://github.com/risense-ai/respire-dsh/commit/1f699bff8deaf6ae4e3c2b93ce18bf7d9deab38b) — `src/index.ts`.
- **Goal query resolution** — uses the goal service `objective` when available; otherwise parses the retained `<goal_round>` `Objective:` JSON. The surrounding “Continue working…” instructions are never used as the query. [`1f699bf`](https://github.com/risense-ai/respire-dsh/commit/1f699bff8deaf6ae4e3c2b93ce18bf7d9deab38b) — `src/index.ts`.
- **Opt-in goal wrap-up** — `goalNudgeEvery` (default `0`) adds at most one goal-round reminder per matching round. Goal rounds never send a store write. [`1f699bf`](https://github.com/risense-ai/respire-dsh/commit/1f699bff8deaf6ae4e3c2b93ce18bf7d9deab38b) — `src/index.ts`.

## Fixes

- **Goal-only turns now create `TurnState`** — closes the previous turn-stopping gap where a turn without a human message had no current turn state. [`1f699bf`](https://github.com/risense-ai/respire-dsh/commit/1f699bff8deaf6ae4e3c2b93ce18bf7d9deab38b).
- **Goal contexts excluded from unintended recall** — `<goal_complete>`, plugin contexts, and rejected goal steps do not reach the engine. [`1f699bf`](https://github.com/risense-ai/respire-dsh/commit/1f699bff8deaf6ae4e3c2b93ce18bf7d9deab38b).
- **Credential-like goal objectives are skipped** before the engine call, with a `Memory: skipped` notice. [`1f699bf`](https://github.com/risense-ai/respire-dsh/commit/1f699bff8deaf6ae4e3c2b93ce18bf7d9deab38b).

## Install / upgrade

Pin this exact version:

```sh
dsh plugin --profile <profile> add @rsrsai/dsh@0.1.13 --save-exact
```

Or through `plugin_manager`:

```json
{"action":"install_bundle","target":"@rsrsai/dsh@0.1.13"}
```

Restart Harness after replacing the bundle. In the Discover tab, add the index source and install `0.1.13` from the version list. `npm install -g @rsrsai/dsh` alone does **not** activate the plugin in a profile.
